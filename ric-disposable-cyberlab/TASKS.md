# Project Tasks

This is a starter split and should be adjusted after the team meets.

## AWS / Infrastructure Lead

- Design AWS architecture
- Build Terraform or CloudFormation templates
- Implement lab launch and teardown workflow
- Configure IAM, networking, and isolation
- Add expiration logic
- Test resource cleanup

## CTF / Platform Lead

- Configure CTFd or another lightweight scoring platform
- Create challenge descriptions and flags
- Test flag submission and scoring
- Document student workflow
- Help design and test the first vulnerable challenge
- Collect feedback from students/instructors

## Shared

- Interview the Cyber Range / cyber club as the customer
- Write business requirements
- Create architecture diagram
- Run end-to-end tests
- Measure provisioning time and estimated cost
- Prepare final demo and presentation

## First Milestone

1. Confirm customer need with RIC Cyber Range / CTF organizers
2. Choose one simple challenge
3. Deploy it manually in AWS
4. Convert deployment to Terraform/CloudFormation
5. Add teardown timer
6. Connect it to CTFd flag submission
