# Project Overview

## Working Title
Disposable AWS Cyber Lab for CTF Training

## Core Idea
Create a repeatable AWS-based cyber lab that can be launched for a student or team, used for a CTF-style challenge, and automatically destroyed when the session expires.

## Why It Matters
The project focuses on reducing manual lab setup/reset work and limiting unnecessary AWS resource cost while preserving hands-on cybersecurity training.

## Intended Customer
RIC Cyber Range / cybersecurity club / instructors running hands-on labs or CTF events.
